# Web Calculator

A clean, responsive web calculator built with HTML, CSS and vanilla JavaScript.

## Features

- Standard operations: addition, subtraction, multiplication and division
- Decimal numbers, delete (DEL) and all clear (AC)
- Dark / light mode toggle (your choice is remembered)
- Physical keyboard support

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| 0 to 9, . | Enter numbers |
| + - * / | Operators |
| Enter or = | Calculate |
| Backspace | Delete last digit |
| Escape | Clear all |

## How to run

Open `index.html` in any modern browser, or use the Live Server extension in VS Code.
